# LabNexus Scope Baseline Index

## Current v1 scope
Single laboratory/site; approximately 1–10 named users; approximately 1–5 simultaneous writers at architectural baseline; Windows single-host deployment; LAN-capable; offline-first; no mandatory Internet/cloud dependency; low expected data volume.

Launch disciplines are Solid Fuel (Coal) and Solid Biofuel. The platform must permit future disciplines without rewriting reusable core mechanisms.

## Explicit v1 boundaries
The project excludes, unless later approved through controlled change, multi-tenancy, multi-site/shared deployment, cloud dependency, public/customer portal, public API ecosystem, ERP/accounting/invoicing/payments, HR/payroll, mobile/field-team workflows, GIS, advanced instrument middleware, enterprise BI/data warehouse, AI/ML decision systems, advanced statistical QC, complex inventory/warehouse management, mandatory automated email/SMS workflows and plugin-framework construction.

## Authority
Detailed scope and exclusions are in `../Main_Prompt.md` §2–3 and `../PreCoding_Questions_v0.8.md` Q21–22. Reconciliations affecting scope are indexed in `project/decision-register.md`, especially PCD-02 and PCD-27.

## Phase 0 restriction
No feature expansion or implementation occurs under this baseline task.
